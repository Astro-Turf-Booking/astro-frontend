# AstroZone typefaces

Self-hosted WOFF2 files downloaded from Fontshare:

- Zodiak Bold (700): `zodiak-bold.woff2`
- Plus Jakarta Sans Regular (400): `plus-jakarta-sans-regular.woff2`

Source CSS: https://api.fontshare.com/v2/css?f[]=zodiak@700&f[]=plus-jakarta-sans@400&display=swap

Loaded through `next/font/local` in `app/layout.tsx`. The page does not request fonts from an external service at runtime.
